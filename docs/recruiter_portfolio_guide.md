# Recruiter Portfolio Guide

## Recommended portfolio order

1. One sentence explaining the business problem.
2. Executive dashboard screenshot.
3. 90-second demo video.
4. Case study showing a decision, not only charts.
5. Architecture and metric definitions.
6. Test status, performance benchmark and source-trust statement.

## Claims that are safe to make

- Built an end-to-end analytics workflow from source files to governed metrics, diagnostics, forecasting, experiments and management reports.
- Implemented deterministic reconciliation tests and explicit provenance labels.
- Added probabilistic scenario analysis rather than presenting point estimates as certainty.
- Created a public multi-table adapter and a separate demonstration profile.

## Claims to avoid

- “Improved company profit” without a real company deployment.
- “Predicts churn accurately” until a labelled model is trained and evaluated on held-out time periods.
- “Production-grade” without identity, authorization, monitoring, backups and operational ownership.
